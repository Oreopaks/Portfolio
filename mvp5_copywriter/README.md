# MVP5 — AI-копирайтер

Генератор продающих текстов под бизнес-задачу. Один короткий бриф на входе —
готовый текст нужного формата на выходе. Работает на `shared.llm.chat`
(GigaChat / YandexGPT / mock).

## Форматы

| Ключ | Формат | Под что |
|------|--------|---------|
| `seo` | SEO-статья (600-900 слов, H1/H2, вхождения ключей) | блог, продвижение |
| `product` | Описание товара (выгода + характеристики + закрытие возражений) | карточки магазина |
| `post` | Продающий пост (крючок + оффер + хэштеги) | соцсети |
| `email` | Письмо рассылки (тема + прехедер + CTA) | email-маркетинг |

## Запуск

```bash
# CLI: формат + бриф
python mvp5_copywriter/copywriter.py seo "ремонт квартир под ключ в Москве"
python mvp5_copywriter/copywriter.py product "беспроводные наушники, шумоподавление"
```

```python
from mvp5_copywriter.copywriter import generate
text = generate("post", "кофейня в центре, акция на раф",
                keywords=["кофейня", "раф"], tone="дружелюбный")
```

## Почему это продукт

- **Закрывает массовую нишу** на биржах (тексты/копирайт — ~17% заказов).
- **4 формата** одним интерфейсом, вхождение ключевых слов и выбор тона.
- **Детерминированная валидация** (формат/пустой бриф → `ValueError`) — тесты без ключей.
