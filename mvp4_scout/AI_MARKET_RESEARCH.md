# Исследование: AI-заказы на РФ-биржах с реальным бюджетом

**Метод.** Снимок 2026-06-22: 552 уникальных листинга, собранных живыми фетчерами скаута
(FL.ru listing+RSS, Kwork, Weblancer) **без фильтров**. Классификация в два прохода:
широкая (по ключам) и жёсткая (требует AI-ядро в тексте + режет не-AI домены).
Бюджет «реальный» = указано конкретное число (не «по договорённости»).

> Ограничение: один снимок, n=552. Для «постится чаще всего» нужен накопленный ряд —
> скаут крутится ежечасно, может копить статистику. Цифры ниже — направление, не истина в последней инстанции.

## Главный вывод

**На массовых биржах AI-работ мало, и дорогие — без указанного бюджета.**

- Широкие ключи: 116/552 (21%) «похоже на AI» — но половина false positive (Битрикс, Тильда, инфографика).
- Жёсткое AI-ядро: **27/552 (4%)**. Из них **только 6 с явной ценой**, остальные 21 — бюджет скрыт.
- Закономерность: дешёвые задачи (1–5k ₽) цену показывают; серьёзные AI-проекты пишут «по договорённости».
  → **гейт по бюджету выкидывает именно хорошие лиды.**

## Где реальные деньги (настоящие AI-лиды из выборки)

- **84 000 ₽** — RAG/умный поиск по документам
- **36 000 ₽** — анализ телефонных разговоров с ИИ (Kwork)
- **30 000 ₽** — голосовой ИИ-бот (промт+интеграция)
- **15 000 ₽** — разработка бота в MAX по аналогу

- «умный консультант», «идентификация по лицу / компьютерное зрение»

Тренд тем (частые слова в заголовках AI-ядра): `python, разработчик, генерация карточек/прайсов
маркетплейсов, умный поиск, бот-консультант, компьютерное зрение/идентификация по лицу`.

## Почему бот шлёт мусор

Текущая сетка ключей (`бот, gpt, api, автоматизация, парсинг…`) ловит не-AI:
- `api` → «Настройка Битрикс 24» (241k, но не AI)
- `бот` → «Прослушивание диалогов», «Позвонить по скрипту»
- `автоматизация/интеграция` → 1С, Тильда, WordPress
- `ии` → «ИИ-инфографика», «повторить работу ИИ в Photoshop»

Нет анти-фильтра на домены, которые тебе НЕ нужны (сайты/копирайт/дизайн/SMM).

## Рекомендации по скауту (фикс «мусора»)

1. **Анти-ключи (blacklist расширить):** `битрикс, 1с, тильда, tilda, wordpress, лендинг,
   сайт под ключ, верстка, seo, smm, копирайт, логотип, дизайн, инфографика, наполнение, photoshop`.
   Резать, только если в заголовке НЕТ AI-ядра (чтобы «бот для сайта» прошёл).
2. **Ключи сузить до AI-ядра:** `gpt, chatgpt, gigachat, yandexgpt, нейросеть, ии, llm, openai,
   ai-агент, чат-бот, gpt-бот, rag, база знаний, голосовой бот, распознавание речи, n8n,
   компьютерное зрение, ocr, генерация карточек`.
3. **НЕ гейтить по бюджету жёстко** — лучшие AI-лиды без цены. Оставить «budget=None проходит»,
   но скрытый-бюджет AI-лид ранжировать выше дешёвого.
4. **Канал тонкий на AI** — это структурное. Доп. источники под AI: Telegram-каналы заказов
   (`digitaltender`, `ipomogator` — у скаута есть `tg_source`, сейчас выключен), Хабр Фриланс.

## Стратегический вывод

На FL/Kwork/Weblancer **AI-поток слабый**: ~4% жёсткого ядра, дорогое прячет бюджет.
Деньги тут берутся не объёмом откликов, а:
- быстрым откликом на редкие AI-лиды (голосовые боты, анализ звонков, RAG, AI-карточки маркетплейсов),
- откликом на «по договорённости» AI-задачи (не ждать цифры в бюджете),
- расширением каналов (TG-каналы заказов) — там плотность AI-заказов выше, чем в общем фиде бирж.
