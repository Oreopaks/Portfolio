# MVP6 — AI-SMM-менеджер

Недельный контент-план + готовые посты под платформу. Тема/ниша на входе —
расписание публикаций с рубриками и тексты постов на выходе.

Архитектура как у скаута: **детерминированная** половина (план рубрик, без LLM)
+ **LLM** половина (тексты постов через `shared.llm.chat`).

## Что делает

- `content_plan(topic, days=7)` — план на неделю: ротация 7 рубрик (Польза,
  Кейс, Закулисье, Оффер, Вовлечение, Разбор мифа, Подборка). Без сети.
- `make_post(idea, platform, topic)` — текст поста под платформу (LLM).
- `week(topic, platform)` — план + готовый пост на каждый день.

Платформы: `telegram`, `vk`, `instagram` (у каждой свой формат/хэштеги).

## Запуск

```bash
python mvp6_smm/smm.py "доставка здоровой еды" telegram
```

```python
from mvp6_smm.smm import content_plan, make_post, week
plan = content_plan("автосервис")          # детерминированно, без ключей
posts = week("автосервис", "vk")           # + готовые посты (нужен LLM)
```


## Почему это продукт

- **Закрывает нишу SMM** (~8% заказов) + смежно с копирайтом.
- **План детерминирован** → демо-расписание показывается без затрат на LLM,
  тексты генерятся по запросу.
- **Разнообразие ленты** из коробки: ротация рубрик вместо семи однотипных постов.
