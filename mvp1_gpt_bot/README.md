# MVP1 — Telegram GPT-бот для бизнеса (демо: кофейня «Кофе Капля»)

Готовый рабочий демо-бот для портфолио фрилансера: умный консультант в Telegram, который
отвечает на вопросы клиентов по базе знаний бизнеса и принимает брони столиков — без
человека на линии, 24/7.

## Что это

Telegram-бот, который:
- здоровается и объясняет, что умеет (`/start`);
- отвечает на вопросы о меню, ценах, часах работы, адресе и частые вопросы (Wi-Fi, оплата,
  растительное молоко и т.д.) — ответ генерирует LLM строго по базе знаний `knowledge.json`;
- ведёт **многошаговую бронь столика**: спрашивает имя, затем дату/время, подтверждает и
  сохраняет заявку в `bookings.csv` (готовый «лид» для владельца).

Вся бизнес-логика вынесена в чистый, тестируемый модуль `handlers.py` — без привязки к сети
и Telegram, поэтому покрывается офлайн-тестами.

## Легенда демо

«Кофе Капля» — уютная городская кофейня на Тверской. Бот заменяет администратора в чате:
мгновенно отвечает гостям и собирает заявки на столики, пока команда варит кофе.
Подменить кофейню на любой другой бизнес — это просто отредактировать `knowledge.json`.

## Структура

| Файл | Назначение |
|------|------------|
| `knowledge.json` | База знаний бизнеса: название, адрес, часы, меню, FAQ |
| `handlers.py` | Чистая логика: `handle_message()`, `save_booking()` |
| `bot.py` | Telegram long-polling (getUpdates + sendMessage через `requests`) |
| `test_bot.py` | Офлайн-тесты (mock-LLM, без токена и сети) |
| `bookings.csv` | Создаётся автоматически при первой брони |

## Как запустить локально

1. Получите токен бота у [@BotFather](https://t.me/BotFather) в Telegram (команда `/newbot`).
2. Задайте переменные окружения (или впишите их в `.env` в корне проекта):

   ```bash
   export TELEGRAM_BOT_TOKEN="123456:ABC-DEF..."   # обязательно
   export LLM_PROVIDER="mock"                        # mock | gigachat | yandex
   ```

   - `mock` — детерминированный ответ без сети и ключей (для демонстрации логики).
   - `gigachat` / `yandex` — реальный LLM; нужны ключи в `.env` (см. `.env.example` в корне).

3. Запустите из корня проекта:

   ```bash
   python mvp1_gpt_bot/bot.py
   ```

   Если токен не задан, бот выведет понятное сообщение и завершится — без трейсбэков.

4. Напишите боту в Telegram: `/start`, затем, например, «сколько стоит латте?» или
   «хочу забронировать столик».

## Чем впечатляет клиента

- **Работает «из коробки» без ключей** — режим `mock` показывает всю логику диалога на любом
  компьютере, демо не зависит от внешних сервисов.
- **Реальная бизнес-ценность**: бот не просто болтает, а собирает лиды (брони) в CSV — это
  деньги, а не игрушка.
- **Заточен под РФ**: из коробки поддерживает GigaChat (Сбер) и YandexGPT — без VPN и
  зарубежных карт.
- **Легко перенести на другой бизнес**: достаточно поменять `knowledge.json`, код не трогаем.
- **Покрыт тестами** — клиент видит инженерную аккуратность, а не «магию на коленке».
